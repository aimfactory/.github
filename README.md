# aimfactory/.github

Organization のデフォルト community health files。

ここに置いた Issue テンプレートと PR テンプレートは、**同種のファイルを持たない** aimfactory 配下のリポジトリで使われる。

## 継承されない条件

リポジトリ自身が `.github/ISSUE_TEMPLATE` を持つ場合、このリポジトリの Issue テンプレートは一切使われない。`pull_request_template.md` も同様で、リポジトリ側にファイルがあるとそちらが優先される。

## 中身

- `.github/pull_request_template.md` — direct-candidate-web の PR テンプレートを正本にしたもの
- `.github/ISSUE_TEMPLATE/機能要件定義.md` — 各リポジトリの機能要件定義の共通本文

プロジェクト別の title 接頭辞（`【SEナビ求職者】` など）は、1 本のテンプレートでは持てないため付けていない。
